# Locus specification

[`specification.md`](specification.md) is the normative language and toolchain
contract for the currently supported file format.

The [`reference/`](reference/) directory contains the relation diagram as
[SVG artwork](reference/relations.svg) and [executable Locus source](reference/relations.locus).
Runnable examples live in [`examples/`](../examples/README.md); shared acceptance
fixtures and test support live in [`tests/`](../tests/README.md).

A FEEDBACK LOOP, BY DESIGN

Write. Check.
Refine. Render.

Locus gives agents the same things a good collaborator needs: readable instructions, specific feedback, and a way to verify the result.

● ● ●YOUR TERMINAL↗
# First, verify the intent.
$ locus check triangle.locus
✓ All assertions passed

# Then, make it visible.
$ locus render triangle.locus -o triangle.svg
→ triangle.svg

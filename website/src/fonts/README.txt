The downloaded font is unmodified. The serif hero line selects its built-in width axis
at 110% and its weight axis at 350 through CSS. Documentation page titles
and the header/footer wordmarks use weight 350 to match the serif hero line.
Other display headings and the hero slogan use its normal width at weight 400. Other character sets use the generic serif fallback.
